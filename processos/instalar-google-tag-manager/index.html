Como instalar o Google Tag Manager no seu site

Dois trechos de código, dois lugares para colar. Se o seu site foi criado com uma IA, tem um prompt pronto logo abaixo — é só copiar e colar na conversa onde você criou a página.

2 passos Leva 2 minutos
Para quem criou o site com IA

Prompt pronto — só copiar e colar

Volte na conversa (ChatGPT, Claude, Lovable, V0, ou o que você usou pra criar o site) e cole o texto abaixo. Ele já explica exatamente o que a IA precisa fazer, com os dois códigos inclusos.

💬 Prompt completo

Copie e cole na IA que criou o seu site

Esse texto já contém os dois códigos do Google Tag Manager e a instrução de onde colar cada um. Não precisa editar nada — é só colar como está.

Preciso que você instale o Google Tag Manager no meu site. São dois trechos de código HTML.

1) Cole este código o mais alto possível dentro da tag <head> da página, antes dos outros scripts:

<!-- Google Tag Manager -->
<script>(function(w,d,s,l,i){w[l]=w[l]||[];w[l].push({'gtm.start':
new Date().getTime(),event:'gtm.js'});var f=d.getElementsByTagName(s)[0],
j=d.createElement(s),dl=l!='dataLayer'?'&l='+l:'';j.async=true;j.src=
'https://www.googletagmanager.com/gtm.js?id='+i+dl;f.parentNode.insertBefore(j,f);
})(window,document,'script','dataLayer','GTM-WNKHH8DK');</script>
<!-- End Google Tag Manager -->

2) Cole este código imediatamente depois da tag de abertura <body>, no topo dela:

<!-- Google Tag Manager (noscript) -->
<noscript><iframe src="https://www.googletagmanager.com/ns.html?id=GTM-WNKHH8DK"
height="0" width="0" style="display:none;visibility:hidden"></iframe></noscript>
<!-- End Google Tag Manager (noscript) -->

Cole os dois exatamente como estão, sem alterar nada, em todas as páginas do site. Depois de aplicar, me confirme que os dois trechos foram adicionados.
🤖 Se uma IA está lendo esta página agora

Se o usuário te enviou o link desta página pedindo pra instalar o Google Tag Manager: copie o Código 1 (mais abaixo, seção "Passo 1") e cole o mais alto possível dentro da tag <head> do HTML, antes de outros scripts. Copie o Código 2 ("Passo 2") e cole imediatamente após a tag de abertura <body>. Aplique em todas as páginas do site, sem alterar o conteúdo dos códigos. Ao terminar, confirme ao usuário que a instalação foi concluída.
